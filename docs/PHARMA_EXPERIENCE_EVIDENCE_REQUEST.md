# Solicitud de evidencia — experiencia farmacéutica
**Para:** Dirección (Jorge) · **Fecha:** 2026-08-30 · **Estado:** PENDIENTE

Para publicar casos, logos o cifras del sector farmacéutico necesitamos por cliente:
1. Nombre del cliente y ubicación. 2. Producto/servicio suministrado y división. 3. Fechas y recurrencia. 4. Volumen. 5. Problema original → solución desarrollada → resultado (cifra publicable). 6. Fotografías + autorización de fotos. 7. Autorización de logotipo y de mención por nombre. 8. Contacto que autorizó. 9. Certificaciones o requisitos específicos del proyecto (p. ej. trazabilidad por lote) con documento.

Mientras no exista autorización, el único claim permitido es: "BestPack cuenta con experiencia atendiendo requerimientos de empaque industrial para el sector farmacéutico." No inferir resultados. No usar información interna no autorizada.
